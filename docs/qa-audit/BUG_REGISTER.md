# Sentiora Bug Register

Audit date: 2026-10-25 · Branch: `fix/get-app-running` (PR #7) · Auditor: Claude Code

Severity: **P0** data loss / compromise / outage · **P1** auth, core-feature or cross-user failure · **P2** partial breakage, integration or portability issue with workaround · **P3** minor.

None of the issues below were introduced by this audit; all existed at the audit baseline (commit `9466abb`). No regressions introduced by the audit fixes have been observed (see TEST_RESULTS.md for what was re-run).

## Fixed during the audit

| BUG-01 | P1 | Extension auth sync | The extension accepted auth tokens **and** logout commands from any page whose hostname *contains* "sentiora" (e.g. `sentiora-login.attacker.example`) or from any `localhost`/`127.0.0.1` port.
